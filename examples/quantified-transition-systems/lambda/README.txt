This archive contains the benchmarks and scripts for the experimental
evaluation of the paper "Universal Invariant Checking of Parametric
Systems with Quantifier-Free SMT Reasoning" submitted to CADE'21.

The contents of the directories is as follows:

benchmarks/ contains the various benchmark instances, divided into three
            groups (protocols, dynarch and trains) as described in the paper

lambda/ contains the source code of our prototype tool

logs/ is an output directory for log files generated by running the various
      run_TOOL.sh scripts

proofs/ is an output directory for proof obligations generated when running
        lambda with the -proof switch

To run the experiments, execute one of the run_TOOL.sh scripts, giving as
input one benchmark instance. The script generates a log file in the logs/
directory. 

For lambda, proof generation can be enabled by using the -proof switch as 1st
argument, before the benchmark instance. In this case, if the verification is
successful, proof obligations are generated in the proofs/ subdirectory.

The scripts for cubicle and mcmt expect to find binaries of the tools in this
directory (called simply "cubicle" and "mcmt" respectively). These binaries
are not provided here, but they can be downloaded from the respecitve
websites.
