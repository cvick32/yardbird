* Reviewed boundaries
- Capture tuples are indexed by canonical model classes but remain distinct
  symbolic applications, including derived applications. Explicit bindings are
  literal. Graph growth rebuilds the occurrence index and resets paging.
- Literal captures disable the model-verified shortcut and source-write
  alternatives, so independent candidate validation checks the actual formula.
- Existential action witnesses are source-defined terms, not newly enumerated
  substitutions. Guard checks precede nested helper use; unknown values remain
  unresolved frontiers and false guards disable the equation.
- Scalar predecessor tracing checks asserted frame bounds and recognizes actual
  state leaves rather than descending through arbitrary witness captures.
- Enabling-condition projection weakens positive update-containing structure;
  mixed negations and guards are dropped conservatively. Projection and trace
  observations are never asserted as lemmas.
- Relational joins propose tuples only. Full binder instances are checked false
  in the current model and pass through the existing ranking/install machinery.
- Hint matching preserves target captures and repeated-variable correlations.
  Typed capture mismatches provide hints only, never asserted model equalities.
- Search remains bounded and read-only with respect to solver assertions and
  the shared graph. The coordinator and installation continue to own mutation.
