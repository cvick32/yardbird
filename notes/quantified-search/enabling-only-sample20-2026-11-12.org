#+TITLE: Original twenty quantified VMT benchmarks after enabling-only tracing
#+DATE: 2026-11-12

* Method
Exact original twenty inputs, in their original order. Sequential unprofiled runs,
depth five (checks 0--4), ten-second cooperative timeout, one-second external grace.
Only completions recorded within ten seconds count. One run per input; this is a
screen, not a repeated timing study. Same preserved binary as the confirmed German
and Chandra run. No compilation or other benchmark batch ran concurrently.

Configuration: --policy countermodel-guided --theory array,quantifiers
--guidance-schedule immediate --guidance-work 4096
--guidance-transition-order predecessor-first
--guidance-action-requirements when-unproductive.

* Results
13/20 complete all five checks; 82/100 checks completed.
The remaining seven time out; client/server reaches the external cutoff, so its
partial-progress file supplies the depth evidence. No error or counterexample
result was reported. Timeout is not evidence of an unsafe system.
