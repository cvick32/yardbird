* Improvements to test, in priority order
1. Schedule a bounded triggered-conflict page earlier after unproductive guidance,
   before the full dependency/witness fallback. Every one of its 70 calls selected
   instances. Dependency discovery selected only one instance directly in 341 calls,
   and witness search selected none in 70 of 82 calls. Empty dependency calls can
   still create requests or useful pending work: do not remove the mechanism or
   assume all its time is dispensable. Preserve fairness and resume pending work.
   Relevant code: src/policy/effort.rs, Stage::Dependencies through Stage::Triggered.
   Current dependency bursts allow up to eight slices before yielding.
2. Add phase timers and evaluation/cache counters within countermodel::search,
   requirements::extend, and countermodel_relations::extend. Guidance consumes
   84.873s, including 72.713s in calls selecting nothing. 97/104 traces exhaust
   their work allowance; 1,594,111 work units produce 25,607 trace nodes.
   There are 7,359 repeated expression occurrences within individual traces, but
   different paths/provenance can be meaningful. Test model-local evaluation
   memoization and shared structural indexes without erasing those links. Invalidate
   truth-value caches on each new model. The current profile does not isolate
   traversal versus relation matching versus AST translation/model evaluation, so
   it cannot yet rank those inner optimizations or predict their speedup.
3. Reduce repeated binder preparation after the above changes. Nested timers show
   17.659s preparing binder search and 6.826s initializing extractors. Reuse only
   model-independent structures; retain model/graph invalidation of equality,
   violation filtering, and match cursors. These times overlap the operation table.

The evidence favors reducing search overhead before solver tuning. Guidance is
still important: it selects 199 instances, and earlier small-budget experiments
failed to reach depth five. Simply disabling it is not supported by this profile.
No performance improvement has been implemented or measured in this profiling turn.
