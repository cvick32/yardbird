* Experimental implementation
- dependency_search::unify_capture_hints permits typed mismatches only at exact
  captured subterms. Repeated quantified variables still use ordinary equality
  checks. Existing unify_modulo remains strict and unchanged for its callers.
- ClauseAgenda::step_capture_hints proposes quantified-value tuples while keeping
  the demanded helper arguments literal in the emitted instance.
- countermodel_relations::extend_observed_witnesses matches false existential
  helper demands to known Boolean trace observations. The resulting introduction
  B=>E is checked by append_trace. If it is satisfied because B is false, tracing
  B can discover missing current-frame array/frame instances. No observed fact
  or capture equality is asserted. Existing work allowance bounds the pass.
- The WhenUnproductive prerequisite gate is unchanged. Initial performance tests
  must use Always to expose the earlier request witness; do not claim a default
  client/server improvement yet.
